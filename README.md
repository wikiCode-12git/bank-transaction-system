# Bank Transaction Simulation System

## 📌 Project Description
This project is a frontend web-based banking system simulation developed using HTML, CSS, and JavaScript. It allows users to perform basic banking operations such as deposit, withdrawal, and transfer.

## 🚀 Features
- User login system
- Deposit and withdrawal
- Fund transfer simulation
- Transaction history
- Data persistence using localStorage

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
